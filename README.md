# Fluorite Flag

Full-colour Python 3 neon minesweeper arcade for ElbowOS.

Clear glowing tiles on a vertical grid. Numbers light up in cyan / mint / gold / magenta. Flag the bombs before they flash. Score climbs as you sweep safe cells.

Left-click reveal. Right-click flag. R restarts.

## Play

```bash
pip install -r requirements.txt
python3 fluorite_flag.py --play
```

## Record a 9:16 reel

```bash
python3 fluorite_flag.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
